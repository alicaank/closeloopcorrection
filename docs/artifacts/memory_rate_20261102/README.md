# Frozen pilot source excerpts

These byte-for-byte audit copies describe the controller and native interventions
used for the November 2 SANA/Lyra pilot. They are not standalone launchers or a
new installed CLI option. The experiment resolved imports against its frozen
local source tree and pinned native environments. Full source hashes, input
paths, queue arguments and results are in `../../memory_rate_evidence_20261102.json`.

`memory_rate_pilot.py` and its test retain the exact pre-generation version.
The package API can contain a documented post-pilot input-validation repair;
the evidence records that difference. `rate_hooks.py` commits measured memory
and applies the optional future translation. `components.py` supplies native
replay and hashing helpers; only its M memory factor is used in this pilot.
`run_rate.py` is the local entry point. The package's existing measured-memory
templates provide related infrastructure, but fresh-machine execution of these
experiment excerpts has not been qualified.
